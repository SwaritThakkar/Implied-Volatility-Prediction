# Implied Volatility Prediction
## This is not the Project Report, for the same, refer to [project_report.md](<project_report.md>).
This repository contains the final submission code and supporting analysis for IITR Finclub Open Projects 2026 PS-2. The task is to reconstruct missing implied-volatility values across the Nifty50 options chain.

The main file is [final_submission.py](final_submission.py). It reads [dataset.csv](dataset.csv), fills the missing option IV cells, and writes a Kaggle-style submission CSV.

For the detailed modeling explanation, EDA, diagrams, and validation discussion, read [project_report.md](<project_report.md>).

## Requirements

Use Python 3.10 or newer. The final submission script needs:

```text
numpy
pandas
scipy
tqdm
```

The optional EDA, README-figure, notebook, and validation scripts may also need:

```text
matplotlib
seaborn
plotly
jupyter
ipykernel
```

Install everything with:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas scipy tqdm matplotlib seaborn plotly jupyter ipykernel
```

On Windows, activate the environment with:

```bash
.venv\Scripts\activate
```

## Recreate The Final Submission

Run the final script from the repository root:

```bash
python final_submission.py --data dataset.csv --out-prefix final
```

This creates the following files in the current working directory:

```text
filled_dataset_final.csv
submission_final.csv
diagnostics_final.csv
cross_section_diagnostics_final.csv
```

To match the repository's packaged final-output folder:

```bash
mkdir -p submission_files
mv filled_dataset_final.csv submission_files/
mv submission_final.csv submission_files/
mv diagnostics_final.csv submission_files/
mv cross_section_diagnostics_final.csv submission_files/
```

The file to submit is:

```text
submission_files/submission_final.csv
```

If you run the script on Kaggle, outputs are written to `/kaggle/working` automatically.

## Run With Internal CV

By default, `final_submission.py` runs a small synthetic internal validation before filling the final dataset. To include that check, omit `--skip-cv`:

```bash
python final_submission.py --data dataset.csv --out-prefix final
```

This prints validation MSE summaries in the terminal and then writes the same four output files.

## Method Summary

The final method treats each timestamp as a same-row implied-volatility smile. Missing CE values are filled using CE values from the same timestamp; missing PE values are filled using PE values from the same timestamp.

The key geometric feature is whether a missing value is an interior gap or an edge wing:

```text
interior gap -> local weighted regression + PCHIP interpolation blend
edge wing    -> progressive extrapolation with primary, secondary, and nearby predictors
```

The submission script parses option metadata from column names, computes moneyness as `strike / underlying_price`, selects local bandwidths with leave-one-out validation, and writes diagnostics for every filled cell.

Full details are in [project_report.md](<project_report.md>).
